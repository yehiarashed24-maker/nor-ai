# NOR AI

NOR AI هو تطبيق ويب مساعد بصري للمكفوفين وضعاف البصر. التطبيق يحوّل ما تراه الكاميرا إلى إجابات صوتية قصيرة وواضحة، ويدعم الاستخدام بالعربية والإنجليزية.

## تجربة الاستخدام الأساسية

بعد الضغط على **اكتشف نور AI** والدخول إلى Assist Mode:

1. يطلب المتصفح صلاحية الكاميرا والمايك أول مرة.
2. تظل الكاميرا مفتوحة كمعاينة مباشرة.
3. يقول نور: «الكاميرا جاهزة. اسألني عن اللي حواليك».
4. يبدأ الاستماع تلقائيًا.
5. يتحدث المستخدم بدون الضغط على Capture أو Send.
6. عند انتهاء السؤال، يلتقط التطبيق Frame واحدة من الكاميرا.
7. يرسل السؤال والصورة فقط إلى Gemini من خلال الخادم.
8. يعرض نور الإجابة وينطقها بصوت واضح.
9. بعد انتهاء الإجابة، يعود تلقائيًا للاستماع للسؤال التالي.

```text
Voice Input
    ↓
MediaRecorder + Voice Activity Detection
    ↓
Capture One Camera Frame
    ↓
Secure Backend API
    ↓
Gemini Multimodal Analysis
    ↓
Short Accessible Answer
    ↓
Text-to-Speech
    ↓
Listen Again
```

الكاميرا تعمل باستمرار داخل Assist Mode، لكن لا يوجد تحليل فيديو مستمر. لا تُرسل أي صورة إلى Gemini إلا بعد أن يسأل المستخدم سؤالًا.

## المميزات المنفذة

### Scene Q&A

وصف المشهد والإجابة عن الأسئلة المتعلقة بالأشياء الظاهرة أمام الكاميرا، مثل: «إيه اللي قدامي؟».

### Read Text

قراءة النصوص الظاهرة على الأوراق واللافتات والمنتجات.

### Social Context

وصف وجود الأشخاص وملابسهم ووضعيتهم وما يفعلونه بصورة عامة، بدون محاولة التعرف على هويتهم أو الادعاء بمعرفة مشاعرهم بدقة.

### Crowd Analysis

إعطاء وصف مختصر لمستوى الزحام وعدد الأشخاص الظاهر تقريبًا.

### Directional Object Guidance

تحديد مكان عنصر ظاهر باتجاه بسيط مرتبط بالصورة، مثل اليمين أو اليسار أو أعلى أو أسفل أو المنتصف. لا يوجد تتبع لليد أو توجيه حركي لحظي.

### Task Guidance

شرح المهام على خطوات قصيرة. يستطيع المستخدم سؤال نور عن الخطوة التالية، فيلتقط التطبيق صورة جديدة للتحقق من الوضع الحالي.

### Memory

عندما يقول المستخدم «افتكر إن ده مكتبي» أو يطلب حفظ معلومة بوضوح، يحفظ التطبيق الذكرى محليًا داخل المتصفح ويرسل آخر الذكريات كجزء من سياق الأسئلة التالية. يحتفظ التطبيق بآخر 12 ذكرى قصيرة.

### Arabic and English

لغة الإجابة تتبع لغة الموقع دائمًا:

- الموقع بالعربية: يجيب نور بالعربية المصرية الطبيعية حتى لو كان السؤال بالإنجليزية.
- الموقع بالإنجليزية: يجيب نور بالإنجليزية حتى لو كان السؤال بالعربية.

يختار التطبيق أفضل صوت عربي أو إنجليزي متاح على الجهاز تلقائيًا، ويستخدم سرعة أبطأ قليلًا للعربية لتحسين الوضوح.

### Fallback Controls

توجد أزرار للمايك والإرسال وتشغيل أو إيقاف الكاميرا كحل بديل عند الحاجة، لكن مسار الاستخدام الأساسي يعمل بالصوت بدون لمس الأزرار.

## الأمان

NOR AI أداة مساعدة بصرية وليست بديلًا للعصا البيضاء أو المرشد أو أنظمة التنقل الآمنة.

- لا يخبر المستخدم أن الطريق آمن للعبور أو الحركة.
- يصف الأشياء الظاهرة ومكانها بدل إعطاء ضمانات سلامة.
- يوضح عندما تكون الصورة غير واضحة ويطلب توجيه الكاميرا مرة أخرى.
- لا يتعرف على هوية الأشخاص من وجوههم.
- لا يدّعي التأكد من المشاعر أو الخطر أو المسافات.
- تكون إجابات الحركة والسلامة وصفية وحذرة.

## الخصوصية

- لا يتم رفع فيديو مباشر.
- يتم التقاط صورة واحدة فقط عند نهاية كل سؤال.
- الصور تُرسل إلى Gemini للتحليل عند الطلب فقط.
- الذكريات محفوظة محليًا في `localStorage` على جهاز المستخدم.
- مفتاح Gemini محفوظ في ملف `.env` على الخادم ولا يصل إلى كود المتصفح أو ملفات البناء.
- ملف `.env` مستبعد من Git بواسطة `.gitignore`.

## المعمارية

### Frontend

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Lucide React

### Browser APIs

- `navigator.mediaDevices.getUserMedia()` للكاميرا والمايك.
- `MediaRecorder` لتسجيل السؤال بصيغة يدعمها المتصفح.
- Web Audio API لاكتشاف بداية الكلام ونهايته بدون إرسال صوت مستمر.
- HTML Canvas لالتقاط Frame واحدة.
- Speech Synthesis لنطق الإجابات.
- `localStorage` لحفظ الذاكرة البسيطة.

### Backend

- Node.js
- Express
- Google Gen AI SDK
- مسار `POST /api/assist` لتحليل السؤال والصورة.
- مسار `GET /api/health` للتحقق من تشغيل الخادم ووجود الإعدادات.

### AI

- Gemini Multimodal
- النموذج الافتراضي: `gemini-3.6-flash`
- تعليمات مخصصة للإجابات القصيرة، اللغة المختارة، الأمان، الذاكرة، والاتجاهات.
- استجابة JSON منظمة تحتوي على الإجابة والذكرى الجديدة عند وجودها.

## الملفات الرئيسية

```text
src/App.tsx
  يفتح ويغلق نافذة Assist Mode.

src/components/AssistantModal.tsx
  الكاميرا والمايك وتسجيل السؤال والتقاط الصورة والنطق
  والاستماع التلقائي والذاكرة.

src/context/LanguageContext.tsx
  لغة الموقع والترجمات واتجاه الصفحة.

server/index.mjs
  خادم Gemini الآمن وتعليمات تحليل الصور والسلامة.

vite.config.ts
  تحويل طلبات /api أثناء التطوير إلى خادم Express.

.env
  مفتاح Gemini والإعدادات المحلية. لا يتم رفعه إلى Git.

.env.example
  نموذج آمن لإعداد متغيرات البيئة بدون مفتاح حقيقي.
```

## التشغيل المحلي

المتطلبات: Node.js حديث ومفتاح Gemini API.

```bash
npm install
npm run dev
```

يشغّل الأمر السابق الواجهة وخادم الـAPI معًا. افتح الرابط الذي يعرضه Vite في المتصفح، ثم اضغط **اكتشف نور AI**.

## متغيرات البيئة

```env
GEMINI_API_KEY=your_key
GEMINI_MODEL=gemini-3.6-flash
PORT=8787
```

لا تضع مفتاحًا حقيقيًا داخل `.env.example` أو أي ملف داخل `src`.

## الأوامر

```bash
npm run dev       # تشغيل الواجهة والخادم
npm run dev:web   # تشغيل واجهة Vite فقط
npm run dev:api   # تشغيل خادم NOR فقط
npm run build     # فحص TypeScript وبناء نسخة الإنتاج
npm run lint      # فحص الكود
npm run preview   # معاينة نسخة الإنتاج
```

## النشر

1. شغّل `npm run build` لإنشاء مجلد `dist`.
2. انشر ملفات `dist` كواجهة الموقع.
3. شغّل `server/index.mjs` في بيئة Node.js.
4. أضف `GEMINI_API_KEY` و`GEMINI_MODEL` و`PORT` إلى متغيرات بيئة الخادم.
5. وجّه طلبات `/api/*` إلى خادم Express.
6. استخدم HTTPS في الإنتاج لأن الكاميرا والمايك يحتاجان سياقًا آمنًا خارج `localhost`.

## حالة المشروع

- اتصال Gemini يعمل وتم اختباره فعليًا.
- الرد بالعربية والإنجليزية حسب لغة الموقع تم اختباره.
- بناء الإنتاج ينجح.
- تجربة الكاميرا والصوت والاستماع التلقائي تعمل على `localhost`.
